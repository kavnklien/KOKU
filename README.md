# 📌 KOKU 

*A Centralized Academic Bulletin and Class Coordination Platform.*

KOKU is a C# ASP.NET MVC web application designed to make classroom communication and academic coordination more organized.

Built to bring official announcements, class schedules, and academic deadlines into one centralized platform, KOKU aims to make important class information easier to access and manage.

<sub>🚧 **Currently a work in progress.** Developed as a final project for COMP 019 - Application Development and Emerging Technologies.</sub>
